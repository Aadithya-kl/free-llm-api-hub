# 06 · Taglines, ronda 2

**Encargo (Paco, vía coordinador, 25-11-2026).** No le convencen "Free LLM APIs, with receipts." ni "Every free AI API has a fingerprint.". Aquí van 20 nuevas en inglés, agrupadas por ángulo. Ninguna usa "receipts" ni "fingerprint" como palabra principal ni clichés tipo *supercharge*, *unlock*, *seamless* o *revolutionary*. También están en la galería "Brand directions".

**Cómo leer las columnas.** *Car.* = caracteres con espacios. Usos:
- **H1** = titular de la portada: ✓ funciona sola · ~ necesita un subtítulo que diga "free AI/LLM APIs".
- **Bio** = descripción del repo en GitHub y bio de redes: ✓ se entiende sin contexto.
- **PH** = titular de Product Hunt (máx. 60 caracteres; caben todas): ✓ engancha en un listado.

★ = una de mis cinco favoritas (el porqué va al final).

## Mis cinco favoritas

1. **#10 "We read the docs. You ship the code."** Explica el valor sin jerga, tiene ritmo y deja al usuario como protagonista. Funciona en las tres posiciones. **Mi recomendación para el H1 de la portada.**
2. **#17 "Know the catch before you sign up."** Es lo que más le importa al dev que va a producción y usa la palabra que ya usa la web ("The catch"). **Recomendada para Product Hunt.**
3. **#5 "Every limit quoted. Every quote dated."** Es el método en seis palabras y la mejor heredera de "with receipts" sin usar esa palabra. **Recomendada para la bio de GitHub** (detrás de #13).
4. **#6 "If the docs don't say it, neither do we."** Es la única que convierte "no consta" en una virtud. Ideal para `/methodology/` y como subtítulo de la tabla.
5. **#9 "Free as in API calls."** La más corta y memorable para devs: pegatina, avatar de redes y camiseta. No sirve sola como H1 para quien llega de Google.
